# networkwalks-B082-week1-Cybersecurrity-lab-setup
# PHASE 1 — Virtual Lab Setup

## Purpose

To set up a secure and isolated virtual cybersecurity lab using Kali Linux and VirtualBox for performing cybersecurity exercises and experiments without affecting the host system.

## Steps

### Step 1 — Install 7-Zip
- Downloaded and installed 7-Zip.
- Used it to extract the downloaded virtual machine files.

### Step 2 — Install VirtualBox
- Downloaded and installed VirtualBox on my laptop/PC.
- Used VirtualBox to create and manage virtual machines.

### Step 3 — Configure VirtualBox Network
- Created a NAT Network in VirtualBox.
- Configured the network range as `10.0.0.0/24`.
- This allows communication between virtual machines within the lab.

### Step 4 — Import Kali Linux VM
- Downloaded the Kali Linux Virtual Machine.
- Imported the VM into VirtualBox.
- Verified that the VM booted successfully.

### Step 5 — Configure Kali Linux IP
- Configured the IP settings of the Kali Linux VM.
- Verified network connectivity within the virtual lab.

### Step 6 — Create VM Snapshot
- Created a snapshot of the configured Kali Linux VM.
- This allows the VM to be restored to its working state if something goes wrong during future experiments.
